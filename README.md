## 制作プロジェクト

### [BookShelf — 書籍レビュー・読書管理アプリ](https://github.com/rn1052289-oss/bookshelf-app)

書籍を探す・レビューする・読書を計画する機能をまとめたLaravel製Webアプリです。

- 書籍検索、ジャンル絞り込み、レビュー、ランキング
- Google Books APIを利用したISBN検索
- 読書計画、リマインダー通知、マイ読書レポート
- Laravel SanctumによるAPI認証と所有者ごとの操作制御

**技術：** PHP / Laravel / MySQL / Blade / JavaScript / Docker

### [お問い合わせ管理アプリ](https://github.com/rn1052289-oss/contact-form-app)

お問い合わせの受付から管理までを扱うLaravel製Webアプリです。

- 入力 → 確認 → 完了のフォームフロー
- 管理者認証、検索・絞り込み、タグ管理、CSV出力
- JSON API、バリデーション、機能テスト・単体テスト
- GitHub Issues / Pull Requestsを使った開発運用

**技術：** PHP / Laravel / MySQL / Blade / JavaScript / PHPUnit
